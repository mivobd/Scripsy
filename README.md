# Bayesian PCA for Process Monitoring and Fault Detection
This repository contains the code used for Daniel Bovim's final-year research project. The final report and poster are also included for any external readers. 
Plagiarism and AI-use declarations have been omitted from the report included in this repository.

Each file *should* be functional as-is.
Some files have adjustable settings at the top after function definitions and housekeeping operations. These settings should each have appropriate comments to describe their use.
This is to prevent the need to sift through all of the code when making slight but repetitive changes for different datasets, algorithms, etc.
